# Training Planner

**Автор:** [Везико]
**Язык:** Python 3.x

## Описание

Приложение для планирования и ведения журнала тренировок. Позволяет добавлять тренировки с указанием даты, типа и длительности. Реализована фильтрация по дате и типу. Данные сохраняются в формате JSON.

## Требования

- Python 3.x.
- Библиотека `tkinter` (входит в стандартную поставку Python).
- (Опционально) `pip install tkcalendar` для расширенного выбора даты.

## Использование

1. Запустите `main.py`.
2. Введите дату (ГГГГ-ММ-ДД), тип тренировки и длительность.
3. Нажмите «Добавить тренировку».
4. Используйте фильтры для поиска записей.
5. Данные сохраняются автоматически в `data.json`.

## Примеры тестов

- Добавьте тренировку с датой `2026-05-02`, типом «Бег», длительностью `30`.
- Попробуйте ввести некорректную дату или отрицательную длительность — появится сообщение об ошибке.
- Примените фильтр по типу «Бег» — в таблице останутся только такие записи.
